THECSPEEDCELL — SITE PROFISSIONAL

Este site envia solicitações para o backend em https://thecspeedcell-site.onrender.com
e consulta o status pelo protocolo retornado. O serviço possui limites de envio
e validação no servidor; a disponibilidade depende do backend e do banco configurado.

O painel da equipe exige o ADMIN_TOKEN configurado no servidor. Digite-o somente
na área de acesso restrito; ele permanece na memória da aba e não é gravado no site.
Nunca coloque tokens no HTML, JavaScript, GitHub Pages ou repositório público.

O WhatsApp abre o contato configurado da ThecSpeedCell. Para alterar o número,
atualize WHATSAPP_URL em script.js e o link de fallback em index.html.

Antes de enviar uma solicitação, o visitante autoriza o uso dos dados para
responder e acompanhar o atendimento. Não solicite senhas nem dados de pagamento
pelo formulário. Consulte o protocolo para ver somente serviço e status; a equipe
autenticada pode consultar os dados de contato no painel.

As imagens são ilustrativas, criadas por IA, e não representam instalações ou reparos reais.

Antes de publicar: implementar backend, autenticação, política de privacidade e tratamento seguro dos dados.
